# 출퇴근 도착정보 (명지 ↔ 서면)

링크 하나로 출퇴근 버스 실시간 도착정보와 1호선 열차 시각을 보는 웹페이지입니다.

- 출근: 명지 더샵퍼스트월드2단지 → 명지1동 행정복지센터(12547) 버스 3 / 128-1 → 하단역환승센터 → 1호선 하단역(노포 방면) → 서면역 12번출구
- 퇴근: 서면역 1호선(다대포해수욕장 방면) → 하단역 → 하단역환승센터(10077) 버스 3 / 128-1 → 명지1동 행정복지센터
- 오후 2시 전에는 출근, 이후에는 퇴근 화면이 먼저 열리고, `바꾸기` 버튼으로 방향을 바꿀 수 있습니다.
- 고정 링크: `?dir=work` (출근), `?dir=home` (퇴근)

## 데이터
- 버스(실시간): 공공데이터포털 `부산광역시_부산버스정보시스템` (15092750), 30초마다 갱신
- 지하철(시간표): 공공데이터포털 `부산교통공사_부산도시철도 열차시각표 조회 서비스_GW` (15158990)
  - 공개된 실시간 열차 도착 API가 없어서 표준 시간표 기준입니다. 실제와 다를 수 있습니다.
  - 하루 한 번 API에서 최신 시간표를 받고, 실패하면 `timetable.js` 내장본을 씁니다.

## 인증키
인증키는 이 저장소에 없습니다. 페이지를 처음 열면 키를 붙여넣는 칸이 나오고, 키는 그 기기 브라우저(localStorage)에만 저장됩니다.
다른 기기는 설정(⚙)의 `설정 링크 복사`로 만든 링크를 나에게만 보내서 한 번 열면 됩니다.

## 경로 바꾸기
정류장, 노선, 탑승 시간은 `config.js`에서 고칩니다.
